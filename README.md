# ChipContour · 树脂断片台

从暗背景下的断片照片测一条实际边缘。先指定原图测量框、从哪个方向进入断片，以及毫米/像素。为避免把断片周围的碎渣当成片身，先在测量框内按亮度下限筛出实际亮像素（任一 RGB 通道为 0 或 255 的点留空），只按上下左右连片；在至少八个连续原行都触到进入方向对侧框边的连片才是候选片身，多片候选时按实际可用面积与到当前截线的距离各占一半评分，采用得分最高的一片。采用后每个原行仍从该侧开始，在同一片身内找第一组至少四个连续实际像素的位置。读数以其首像素到同侧观察框的距离表示。证据缺失处在走势中留空。截线图上会标出确属采用片身的亮点，PNG 校样只标该片身的原边，亮度仍按真实像素读取。

“打开练习断片”使用明确标记的合成照片。也可以上传单帧 PNG、JPEG、TIFF、BMP 或 WebP。可在原照点读 RGB、选择原截线，查看截面和边缘走势，保存后下载原值 CSV、PNG 校样和含原照的ZIP，或者把原照送到照片准备。

`docker compose up --build` 后访问 `http://127.0.0.1:19922/`。服务仅监听本机，命名卷保存数据。
