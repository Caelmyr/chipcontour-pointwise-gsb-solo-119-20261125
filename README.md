# ChipContour · 树脂断片台

从暗背景下的断片照片测一条实际边缘。先指定原图测量框、从哪个方向进入断片，以及毫米/像素。每个原行从该侧开始找第一组至少四个连续像素达到亮度阈的位置。读数以其首像素到同侧观察框的距离表示。证据缺失处在走势中留空。

“打开练习断片”使用明确标记的合成照片。也可以上传单帧 PNG、JPEG、TIFF、BMP 或 WebP。可在原照点读 RGB、选择原截线，查看截面和边缘走势，保存后下载原值 CSV、PNG 校样和含原照的ZIP，或者把原照送到照片准备。

`docker compose up --build` 后访问 `http://127.0.0.1:19922/`。服务仅监听本机，命名卷保存数据。
